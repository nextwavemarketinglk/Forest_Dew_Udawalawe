# Forest Dew V4 — Clay & Ivory Boutique Edition

## New direction
The original green-heavy safari look has been replaced with an original boutique hospitality art direction. Palette: ivory (#FBF5EC), ink/espresso (#302930), sun-baked terracotta (#B66E58), muted dune (#E8D8C4), and soft sky-blue (#577C84). Warm Cormorant Garamond serif + DM Sans UI.

## What changed
- Complete homepage hero redesign: split editorial layout, original typography, actual hotel images and image rotation.
- Redesigned fixed light header, navigation, booking ribbon and mobile menu.
- Asymmetric room and experiences grids, fresh room card surfaces, safari package cards, photo gallery, warm forms, modern footer and interior-page visual treatment.
- Existing room / safari prices and functional booking-enquiry JavaScript preserved.
- No guest portrait photos published; no misleading stock hotel photos added. Wildlife conceptual artwork remains in relevant safari storytelling, clearly described.
- Designed for GitHub + Cloudflare Pages, no build step.

## Before launch
Verify phone and WhatsApp capability, contact/address, per-night pricing assumption, exact room-photo mapping, safari inclusions, booking policies and actual dates/availability with property owner.
For privacy, obtain guest permission before public display.
